# إعلانات المحاضرات

موقع ثابت (بدون خادم) يحوّل ملف الإكسل إلى إعلانات جاهزة على القالب، مع باركود كل مسجد.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (يُفضّل **Private**؛ GitHub Pages للمستودعات الخاصة يحتاج حساباً مدفوعاً، وإلا فالمستودع العام يعني أن أي شخص يستطيع فتح الموقع).
2. ارفع كل محتويات هذا المجلد (index.html و assets و data وغيرها) إلى الفرع main.
3. من Settings ← Pages ← Source: `main` / root.
4. الرابط يظهر بعد دقيقة تقريباً. ويمكن أيضاً فتح `index.html` مباشرة من الجهاز.

## الاستخدام
- **استيراد ملف**: يقبل ملف الوزارة كما هو، أو `محاضرات_جاهز.xlsx`. الأعمدة: اليوم، التاريخ، الوقت، المسجد، الداعية، العنوان، رقم الفسح.
- المسجد يحدد الباركود تلقائياً. التواريخ بصيغة `يوم/شهر` أو `1448/5/8`.
- **تخصيص التصميم**: حجم وموضع وخط كل عنصر. التعديلات تُحفظ في المتصفح.
- **تصدير**: JPG / PNG / PDF، إعلان واحد أو المحدد أو الكل (ZIP).

## إضافة باركود جديد دائماً
ضع الصورة في `assets/qr/` وأضف سطراً في `data/qr.js` (الاسم، المسار، وأسماء بديلة aliases إن وُجدت).

الخطوط تُحمَّل من Google Fonts، فيلزم اتصال بالإنترنت أول مرة (أو ارفع الخط الذي تريده من لوحة التخصيص).
